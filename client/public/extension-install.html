Ordi Wallet · Desktop browser preview

Install the local vault extension

Manage a locally encrypted Bitcoin and Fractal wallet across all four address types, inspect live protocol balances and recent sent/received chain activity, and review/sign locally supported BTC, FB and single-Ordinal transfers from the desktop browser popup.

Extension package version: 0.6.0.

Get the preview package

Install in a Chromium browser

  1. Download and unzip the package.
  2. Open chrome://extensions (or edge://extensions) and turn on Developer mode.
  3. Select Load unpacked and choose the unzipped folder containing manifest.json.
  4. Pin Ordi Wallet, open it, then create a new vault or import a recovery phrase you control.

Works as a developer-loaded extension in desktop Chrome, Edge, Brave, and other Chromium-based browsers.

Firefox desktop

  1. Unzip the package.
  2. Open about:debugging#/runtime/this-firefox.
  3. Select Load Temporary Add-on… and choose manifest.json.

Firefox temporary add-ons are removed when Firefox restarts. Permanent Firefox distribution requires Mozilla signing; this preview is not signed.

Security and compatibility

  • The extension encrypts its own vault locally. Never enter a recovery phrase into a page you do not trust.
  • Extension storage is isolated from a website’s local storage. To use the same wallet in a site vault, import the same phrase there; the preview does not silently share keys or automatically inject a website provider.
  • Live portfolio data covers all four address types for the selected network; local signing is limited to ordinary BTC/FB and single-Ordinal transfers. BRC-20, BRC20-Prog, Runes and Alkanes are indexer views/external routes only and are not locally signed by this build.
  • This is a desktop browser extension. Mobile website layouts remain responsive, but mobile browsers generally do not support installing this extension.
  • Safari, store installation, and automatic cross-site wallet connection are not included in this preview.

Do not use this unsigned preview with funds you cannot afford to lose. Review the source and test with a wallet containing no valuable assets first.
